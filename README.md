# Student Performance Prediction

## About the Project
This is a Python programming using AI & DS project that uses Machine Learning to predict students' academic performance based on factors such as study time, absences, parental support, and extracurricular activities.

## Technologies Used
- Python
- Google Colab
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Machine Learning (Random Forest, Logistic Regression)

## Dataset
The dataset contains student information, study habits, GPA, and academic performance which I taken it from the Kaggle website. 

## Project Goals
- Analyze student performance data.
- Visualize important patterns.
- Train Machine Learning models.
- Predict students' GradeClass.

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Model Training
6. Model Evaluation
7. Student Performance Prediction
